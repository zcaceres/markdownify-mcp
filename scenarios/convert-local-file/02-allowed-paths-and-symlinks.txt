# Slice 02: Allowed Paths, Symlinks, and HTTP Fail-Closed Policy (LF-3, LF-4)

# LF-4 (D6, I2): MD_ALLOWED_PATHS permits files inside configured directories (including via ~ expansion)
> config set MD_ALLOWED_PATHS /data:~/docs
config MD_ALLOWED_PATHS = /data:~/docs

> filesystem put /data/report.pdf
created file /data/report.pdf

> filesystem put /home/user/docs/memo.docx
created file /home/user/docs/memo.docx

> markitdown stub # Allowed Doc
markitdown stubbed

> convert pdf-to-markdown /data/report.pdf
ok: pdf-to-markdown (path: none)
| # Allowed Doc

> convert docx-to-markdown ~/docs/memo.docx
ok: docx-to-markdown (path: none)
| # Allowed Doc

# LF-4 (D21, I2): out-of-bounds missing file, .. traversal, and prefix-sibling are rejected BEFORE existence checks
> convert pdf-to-markdown /etc/does-not-exist.pdf
error: Path "/etc/does-not-exist.pdf" is outside the allowed directories. Set MD_ALLOWED_PATHS to a :-separated list that includes a parent directory (currently allowed: /data:/home/user/docs).

> convert pdf-to-markdown /data/../etc/passwd
error: Path "/data/../etc/passwd" is outside the allowed directories. Set MD_ALLOWED_PATHS to a :-separated list that includes a parent directory (currently allowed: /data:/home/user/docs).

> filesystem put /data-evil/secret.pdf
created file /data-evil/secret.pdf

> convert pdf-to-markdown /data-evil/secret.pdf
error: Path "/data-evil/secret.pdf" is outside the allowed directories. Set MD_ALLOWED_PATHS to a :-separated list that includes a parent directory (currently allowed: /data:/home/user/docs).

# LF-4 (I2): symlink inside Allowed Paths targeting outside is rejected; symlink staying inside is permitted
> filesystem put /outside/secret.pdf
created file /outside/secret.pdf

> filesystem symlink /data/escape.pdf /outside/secret.pdf
created symlink /data/escape.pdf -> /outside/secret.pdf

> convert pdf-to-markdown /data/escape.pdf
error: Path "/data/escape.pdf" is outside the allowed directories. Set MD_ALLOWED_PATHS to a :-separated list that includes a parent directory (currently allowed: /data:/home/user/docs).

> filesystem symlink /data/alias.pdf /data/report.pdf
created symlink /data/alias.pdf -> /data/report.pdf

> convert pdf-to-markdown /data/alias.pdf
ok: pdf-to-markdown (path: none)
| # Allowed Doc

# LF-4 (D8, D24): explicitly set empty or delimiter-only MD_ALLOWED_PATHS fails closed (never falls back to unrestricted)
> reset
the world is back to its fixtures

> config set MD_ALLOWED_PATHS :
config MD_ALLOWED_PATHS = :

> filesystem put /data/doc.pdf
created file /data/doc.pdf

> convert pdf-to-markdown /data/doc.pdf
error: MD_ALLOWED_PATHS is set but contains no valid directories. Specify at least one directory or unset MD_ALLOWED_PATHS.

# LF-4 (D6, D23): legacy MD_SHARE_DIR is ignored now that MD_ALLOWED_PATHS is the sole variable
> reset
the world is back to its fixtures

> config set MD_SHARE_DIR /legacy

markitdown stubbed

# LF-3 (D6, D8, D9, D23): HTTP mode fails closed on local file tools when Allowed Paths is unset, unless explicitly opted out
> reset
the world is back to its fixtures

> config set MCP_TRANSPORT http
config MCP_TRANSPORT = http

> filesystem put /data/report.pdf
created file /data/report.pdf

> convert pdf-to-markdown /data/report.pdf
error: Local file tools are disabled in HTTP mode when MD_ALLOWED_PATHS is unset. Set MD_ALLOWED_PATHS, or pass --allow-unrestricted-paths / MCP_ALLOW_UNRESTRICTED_PATHS=true to opt out.

> config set MCP_ALLOW_UNRESTRICTED_PATHS true
config MCP_ALLOW_UNRESTRICTED_PATHS = true

> markitdown stub # Opted Out
markitdown stubbed

> convert pdf-to-markdown /data/report.pdf
ok: pdf-to-markdown (path: none)
| # Opted Out
