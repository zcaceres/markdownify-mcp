# WU-6, WU-13 (D13): MD_* env var overrides tighten or raise limits, and invalid values fail cleanly
> reset
the world is back to its fixtures

> config set MD_FETCH_TIMEOUT_MS 5000
config MD_FETCH_TIMEOUT_MS = 5000

> network stub https://example.com/medium 200 <h1>Medium</h1>
stubbed https://example.com/medium -> 200

> network slow https://example.com/medium 8s
network latency for https://example.com/medium -> 8000ms

> convert webpage-to-markdown https://example.com/medium
error: Fetch timed out after 5000ms for https://example.com/medium

> config set MD_FETCH_TIMEOUT_MS 10000
config MD_FETCH_TIMEOUT_MS = 10000

> markitdown stub # Medium
markitdown stubbed

> convert webpage-to-markdown https://example.com/medium
ok: webpage-to-markdown (path: none)
| # Medium

> config set MD_MAX_REDIRECTS 1
config MD_MAX_REDIRECTS = 1

> network redirect https://example.com/h0 302 https://example.com/h1
redirected https://example.com/h0 -> 302 https://example.com/h1

> network redirect https://example.com/h1 302 https://example.com/h2
redirected https://example.com/h1 -> 302 https://example.com/h2

> network stub https://example.com/h2 200 <h1>H2</h1>
stubbed https://example.com/h2 -> 200

> convert webpage-to-markdown https://example.com/h0
error: Too many redirects

> config set MD_MAX_DOWNLOAD_BYTES bad
config MD_MAX_DOWNLOAD_BYTES = bad

> convert webpage-to-markdown https://example.com/medium
error: Invalid MD_MAX_DOWNLOAD_BYTES "bad": must be a positive integer
